# 법률 검토가 필요한 항목 (2026-10-19 개편)

사이트 문구는 사실 기준으로 썼고 소비자심리 게이트를 통과했지만, 아래는 법률 전문가 확인이 필요하다.
화면에는 "검토 중" 표시를 하지 않았다(공개 페이지에 초안 표시를 띄우지 않기 위해). 키 이름은 `hub-site/src/i18n/*.json`.

| 페이지 | 키 | 왜 검토가 필요한가 |
|---|---|---|
| /terms | tm_1_p ~ tm_5_p | 이용약관 전체가 사실 기반 최소 문안이다. 면책 범위·준거법·분쟁 관할이 없다. |
| /privacy | pv_1_p ~ pv_7_p | 실제 수집 항목(다운로드 1행: 시각·플랫폼·국가·참조 호스트·UTM·랜딩 경로·접속 유형·Sec-Fetch-Site / 게시판 글 / 세션 저장소)을 코드에서 확인해 적었다. 개인정보보호법상 고지 항목(보관 기간·파기·처리 위탁(Cloudflare)·국외 이전)이 빠져 있다. |
| /risk-disclosure | rk_1 ~ rk_11 | 고위험 금융상품 위험 고지로 충분한지(표시광고법·유사투자자문 경계). 특히 rk_10(브로커 수수료 공유)·rk_11(투자 조언 아님). |
| /how-it-works | hiw_s3_* | 브로커 수수료 공유 비율(비트겟 12%)·바이낸스 신규 가입자 조건·카피 트레이딩 리더 수익 배분 공개 문구. |
| /copy-trading | ct_* | 개발자가 리더인 카피 트레이딩 프로필로 연결(초대 코드 포함). 팔로워 모집이 유사투자자문·투자권유에 해당하지 않는지. |
| /exchange, / | perf_*, m_* | 실계좌 1개(가족1 계좌)의 대시보드 캡처·수치 공개. 계좌 소유자 동의 여부(사용자가 확인), 성과 표시 방식. |
| 전 페이지 | foot_tm | 거래소 상표·로고 사용과 비제휴 고지. |

※ 사용자 지시로 "결과를 보장하지 않습니다 / 과거 성과는 미래를 보장하지 않습니다" 문장은 쓰지 않았다. SPEC 이 요구한 "과거 성과의 한계"는 rk_3_p("다른 계좌·기간·종목·설정에서는 손실을 포함해 전혀 다른 결과가 나올 수 있습니다")와 riskbox_p("다른 계좌의 결과는 다를 수 있습니다")로 표현했다. 법률 검토에서 보장 부정 문구가 필수라고 판단되면 사용자에게 다시 물어야 한다.
