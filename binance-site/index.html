FAQ

The Questions You'd Ask Before Paying

…except there's nothing to pay. It's free. Still, here's what you'll want to know:

Is it really free? No hidden costs?
Yes — no subscription, no purchase price, no performance fee. The only revenue source is Binance's official Broker Program: a share of the trading fee you already pay Binance gets rebated to us, by Binance.
Is it safe to enter my API key?
Your API key is encrypted and stored locally on your own PC — it is never transmitted anywhere, and withdrawal permission is never required.
Are profits guaranteed?
No. It's a tool that executes a defined strategy 24/7 without emotion. Crypto futures carry a serious risk of loss — validate in Shadow Mode before going live.
How close is Shadow Mode to real trading?
Shadow Mode uses the real exchange's live API with virtual USDT — signals, timing, and data are identical to live trading; only the real orders are withheld.
What happens if my PC shuts down mid-trade?
New entries and position management stop. Positions already open remain on the exchange, and the bot re-detects and resumes managing them on restart. An always-on mini PC or low-cost cloud VM is recommended.
What's the minimum capital?
We recommend 1,000 USDT or more so per-trade sizing (up to 1/300th of balance) stays above exchange minimum-notional limits.
What about flash crashes and liquidation risk?
Five layers of exit logic manage every position, but no system can fully eliminate the risk of violent moves in futures markets. Keep leverage conservative.
Can I use it without knowing how to code?
Yes — download, double-click start.bat, paste your API key, pick coins, start. No code, anywhere. The User Manual covers it in 9 real screens.
Which exchanges and markets are supported?
Currently Binance USDⓈ-M Futures only, monitoring 500+ symbols simultaneously.
Does it run on Windows and macOS?
Yes — both. No high-end hardware needed, just a PC that stays on 24/7 with an internet connection.
Do I have to sign up through your referral link?
You can use an existing account, but only partner-link signups generate the fee rebate that keeps this software free.
How do I set up Telegram alerts?
Enter your bot token and chat ID in Settings — you'll get balance, P&L, ROI, win rate and open-position reports on request or on schedule.
What's the refund policy?
The price is $0, so there's nothing to refund. Delete it anytime — no cancellation flow, no penalty.
How do updates work?
New versions are announced on this page and in the Telegram channel. Download and overwrite — settings are preserved.
