Computed from the trade records of one real, running account

Closed trades and funding fees only. The program has no stop-loss by default, so apart from a delisting exit or a liquidation it does not close a losing position on its own. A loss shows up in these numbers only once a position is closed at a loss; until then it stays in an open position. Open positions are not in these numbers — you can see them on the “Open positions” screenshot exactly as the dashboard shows them.

The dashboard's “Total N Trades” and Win Rate also count funding-fee entries. Here funding is counted separately, which is why the two sets of numbers differ. A trade closed at exactly 0 counts as neither profit nor loss.

What the program does

Runs on your PC Available

Orders go from your computer straight to the exchange with your own API key. There is no server of ours in between.

Shadow Mode Available

Runs the strategies on live prices with a virtual balance, so you can watch it before any real order is placed.

3 strategies, 500+ symbols Available

You choose which USDⓈ-M futures symbols it watches. The strategies are tuned for high-volatility altcoins.

Entry limits by default Available

Skips symbols listed less than 90 days ago. After 3 new entries on the same symbol and side within 24 hours, it blocks new entries until 48 hours after the first one. Adding to an open position does not count toward this limit.

Delisting filter Available

Stays away from symbols with an announced delisting, based on the exchanges' public announcements.

No stop-loss by default Available

A position can stay in a deep loss for a long time. An optional 60% hard stop is available in Settings.

Large-cap (BTC/ETH) preset In development

A preset tuned for large-cap symbols is being developed. It is not in the current build.

Android On hold

The Android build is on hold until it runs reliably. Windows and macOS only for now.
