사용 방법

실제 프로그램 화면입니다(비트겟 빌드, 영문 화면, 가짜 예시 키, 아무것도 연결하지 않은 상태). 다른 거래소 빌드도 탭과 버튼이 같으며, 차이점은 맨 아래에 적었습니다.

권장: 쉐도우 모드로 먼저 지켜보기

Start Trading 을 누르기 전에 Operations Console 에서 쉐도우 모드를 켜고 며칠 돌려 보세요. 실주문 없이 실제 시세에서 같은 판단을 볼 수 있습니다.

1다운로드 · 압축 해제 · 실행

사용하는 거래소용 파일을 받아 압축을 풉니다. Windows 는 JaviD_Future_Bot.exe, macOS 는 start.command 를 실행합니다. 프로그램은 내 PC의 로컬 주소로 브라우저에서 열립니다. 첫 실행 안내 창을 닫으면 탭이 보입니다.

2Settings — API 키 입력 후 Save

Settings 탭을 열고, 거래소에서 만든 Access Key 와 Secret Key 를 붙여 넣은 뒤(비트겟·OKX 는 Passphrase 도) Save 를 누릅니다. 옆의 Test Connection 으로 키를 확인할 수 있습니다. 키의 출금 권한은 꺼 두세요.

3Settings — 투자금액 (Investment Mode)

Investment Mode (Margin Ratio per Entry) 에서 진입마다 잔고의 얼마를 쓸지 고릅니다: 진입당 증거금 = 잔고 ÷ 100·200·300·500·700. 기본값은 Normal(÷ 500) 이고, 숫자가 클수록 한 번에 들어가는 금액이 작아집니다. 모드를 누르면 바로 적용됩니다. (바이낸스 빌드는 Aggressive·Normal·Stable 세 가지입니다.)

4Settings — 진입 모드

Entry Mode 에서 Conservative (single)(처음 조건이 맞는 전략 하나만) 또는 Multi Mode(전략을 번갈아 사용)를 고릅니다. 고르면 바로 적용됩니다.

5Settings — 레버리지

Leverage 에서 3x·5x·10x·15x 중 고릅니다. 새로 설치하면 10x 입니다. 다음 신규 진입부터 적용되고, 이미 열린 포지션은 기존 레버리지를 유지합니다. 레버리지가 높을수록 청산 가격이 가까워집니다.

6Symbol Selection — Select All

Symbol Selection 탭에서 Select All 을 누릅니다(원하는 종목만 골라도 됩니다).

7Symbol Selection — Save Selection

Save Selection 을 누릅니다. 이후 선택한 모든 종목의 캔들 데이터를 불러오니 끝날 때까지 기다립니다.

8Start Trading 누르기

오른쪽 위 Start Trading 을 누릅니다. 오른쪽 Operations Console 의 Shadow Mode(기본값 꺼짐)가 켜져 있으면 가상 잔고로 매매합니다. 쉐도우 모드를 끈 상태라면 실주문 전에 레버리지·증거금 요약 확인 창이 뜹니다.

거래소별 빌드 차이

  • 비트겟: Access Key · Secret Key · Passphrase. 키에 선물 조회·거래 권한이 필요합니다.
  • 바이낸스: Access Key · Secret Key 두 칸뿐입니다. 투자모드는 Aggressive·Normal·Stable 입니다.
  • 바이비트: API Key · API Secret, 패스프레이즈 없음. 통합 거래 계정(UTA)이어야 하고 USDT 가 있어야 하며, 키에는 계약 주문·포지션 읽기·쓰기 권한이 필요합니다. 바이비트 키는 18자이며 정상입니다.
  • OKX: API Key · Secret Key · Passphrase. 계정 모드가 “선물 모드”여야 하고 USDT 가 거래 계정에 있어야 합니다. (다운로드 준비 중)
  • 모든 빌드: 키의 IP 바인딩을 권장하며, 첫 실행 때 헤지(양방향) 모드가 자동으로 켜집니다.

레버리지 선물은 원금 전액 손실이 가능합니다. 레버리지가 높을수록 청산 가격이 가까워집니다. 기본값에는 손절이 없어 포지션이 큰 손실 상태로 오래 남을 수 있습니다. 60% 하드스톱을 켜면 손실 크기를 제한할 수 있지만, 그 시점에서 손실이 확정됩니다.
