처음 실행할 때 컴퓨터가 경고합니다

윈도우와 macOS 는 코드 서명 인증서로 서명된 프로그램에만 이 경고를 생략합니다. 매년 갱신하는 유료 항목이고 사업자 등록이 있어야 발급됩니다. 저는 그걸 사지 않았습니다. 그래서 컴퓨터는 사실을 말하고 있는 겁니다 — 누가 배포했는지 확인할 수 없다는 것. 이건 바이러스 검사 결과가 아니고, 프로그램이 무슨 일을 하는지에 대한 판단도 아닙니다.

macOS — 게이트키퍼도 같은 일을 합니다

macOS 배포본은 설치 파일이 아니라 폴더입니다. 압축을 풀고 안에 있는 start.command 를 여세요. 파이썬과 필요한 라이브러리가 이미 그 폴더에 들어 있어서 설치 단계가 없고, 응용 프로그램 폴더에도 아무것도 추가되지 않습니다. 설정도 로그도 전부 그 폴더 안에만 쌓이고, 폴더를 휴지통에 넣는 것이 삭제의 전부입니다.

macOS 15+

“start.command”이(가) 열리지 않았습니다
Mac에 손상을 주거나 개인정보를 침해할 수 있는 악성 소프트웨어가 없는지 Apple이 확인할 수 없습니다.
휴지통으로 이동완료

일단 한 번 열어 실패하게 두세요. 그다음 시스템 설정 → 개인정보 보호 및 보안 으로 가서 아래로 내리면 “무시하고 열기”가 있습니다. 이 경로를 먼저 적는 이유는 macOS 버전을 타지 않기 때문입니다.

macOS 14

“start.command”을(를) 열 수 없습니다
확인되지 않은 개발자가 배포했기 때문입니다.
취소열기

start.command 를 Control-클릭 → 열기 → 대화상자에서 다시 열기. 메뉴에 “열기”가 없으면 위의 시스템 설정 경로를 쓰세요.

정확한 문구는 macOS 버전마다 다릅니다. 화면이 이것과 비슷하지만 똑같지는 않다면, 제대로 온 것이 맞습니다.

V19.7 변경 사항

  • 기본 안전장치: 상장 90일 미만 종목 진입 금지, 같은 종목·방향에 24시간 안 3회 신규 진입하면 첫 진입부터 48시간까지 신규 진입 잠금, 현물 상장폐지까지 포함한 상장폐지 필터.

  • 고급 위험관리·전략 설정은 비밀번호로 잠겨 있고, 60% 하드스톱 스위치는 계속 보입니다.
  • 수정: 바이비트 키(18자)에서 'API 키 입력' 단계가 계속 깜빡이던 문제.

다운로드 관련 질문

정말 무료인가요?
네. 구독이나 유료 등급이 없습니다. 개발자는 거래소 브로커 프로그램을 통해 사용자가 이미 내는 거래 수수료의 일부를 받을 수 있습니다 — 자세한 내용은 작동 방식 페이지에 있습니다.
프로그램에 출금 권한이 필요한가요?
아니요. 선물 거래 권한만으로 키를 만들고 출금 권한은 꺼 두세요. 거래소가 지원하면 키를 내 PC의 IP 주소로 제한하세요.
손실이 날 수 있나요?
네. 레버리지 선물은 원금 전액 손실이 가능하고, 기본값에는 손절이 없습니다. 쉐도우 모드로 시작하고, 잃어도 되는 돈만 쓰세요.
거래소 계정이나 API 키 없이 써 볼 수 있나요?
쉐도우 모드는 실제 시세로 전략을 돌리되 가상 잔고로 기록합니다. 실주문을 내려면 계정과 API 키가 필요합니다.
어떤 운영체제에서 실행되나요?
Windows 와 macOS 입니다. 안드로이드는 보류 중이고 iOS 버전은 없습니다. 매매하는 동안 컴퓨터가 켜져 있어야 합니다.
실행할 때 Windows·macOS 가 왜 경고하나요?
개인 개발자가 만든 프로그램이라 유료 코드서명 인증서로 서명되어 있지 않아, 운영체제가 게시자를 확인하지 못합니다. 다운로드 페이지에 여는 방법과 파일의 SHA-256 체크섬 확인 방법이 있습니다.
