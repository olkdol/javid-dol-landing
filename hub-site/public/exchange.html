Computed from the trade records of one real, running account

Closed trades and funding fees only. The program has no stop-loss by default, so apart from a delisting exit or a liquidation it does not close a losing position on its own. A loss shows up in these numbers only once a position is closed at a loss; until then it stays in an open position. Open positions are not in these numbers — you can see them on the “Open positions” screenshot exactly as the dashboard shows them.

The dashboard's “Total N Trades” and Win Rate also count funding-fee entries. Here funding is counted separately, which is why the two sets of numbers differ. A trade closed at exactly 0 counts as neither profit nor loss.

Backtest

No verified backtest result yet.

An earlier published backtest had a counting error — overlapping time windows counted some positions twice — so it was withdrawn. A backtest appears here only after it passes every check below, and it is never added to live results. If you have seen our earlier backtest figures elsewhere, those figures are withdrawn.

Publication rules

  1. Same strategy code and default settings as the released build, with the build version stated.
  2. Period, symbol universe and price data source stated.
  3. Trading fees, funding fees and slippage: each marked as included or not.
  4. Survivorship bias stated: whether delisted symbols were included.
  5. Each position counted once (no overlapping-window double counting).
  6. Headline figures recomputed from the trade list must match.
  7. The latest verified run is shown; earlier runs and the reason they changed are kept in a change log.
  8. Shown apart from live records and never summed with them.

The records on this site come from one account over a limited period, and your results can be different. Nothing here is investment advice.
