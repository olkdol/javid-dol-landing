Privacidad

Última actualización: 2026-10-19

El programa

El programa se ejecuta en tu ordenador. Tu clave API y tu configuración se guardan allí. El programa no envía tu clave, tu saldo ni tus operaciones al desarrollador.

Descargas

Cuando descargas una versión, el servidor de descargas del subdominio de ese exchange (bg., bn. o bb.javidtrading.com) registra una fila: la hora, la plataforma (Windows o macOS), el país que indica la red, el nombre de host del sitio de procedencia, las etiquetas de campaña UTM, la página de este sitio desde la que llegaste, un tipo de cliente aproximado (navegador, bot, script) y el valor Sec-Fetch-Site del navegador. No se guardan tu dirección IP ni el user agent completo. Lo usamos para contar descargas y ver qué canales funcionan.

Almacenamiento del navegador

Este sitio guarda desde dónde llegaste en el almacenamiento de sesión de tu navegador (se borra al cerrar la pestaña) para que una descarga pueda atribuirse a ese canal.

Foro de la comunidad

Se guardan el nombre y el mensaje que publicas. En las publicaciones privadas se guarda un hash con sal de tu contraseña, no la contraseña.

Correo electrónico y Telegram

Si nos escribes, conservamos la conversación para responderte.

Terceros

El sitio se sirve a través de Cloudflare. Las fuentes tipográficas se cargan desde jsDelivr. Los enlaces a exchanges y a YouTube te llevan a esos servicios, sujetos a sus propias políticas.

Contacto

Preguntas o solicitudes de eliminación: support@javidtrading.com.
