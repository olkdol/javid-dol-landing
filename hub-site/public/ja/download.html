レバレッジをかけた先物取引では、元本をすべて失う可能性があります。 レバレッジが高いほど、強制ロスカット（清算）が近づきます。初期設定ではプログラムにストップロスがないため、ポジションが大きな損失を抱えたまま長期間残ることがあります。任意の 60% ハードストップはこれを制限しますが、その代わりに損失が確定します。

初回起動時：コンピューターが警告を表示します

WindowsとmacOSは、コード署名証明書で署名されたソフトだけこの警告を省きます。毎年更新の有料項目で、法人登録が必要です。私はそれを買っていません。ですからパソコンは事実を言っています — 誰が配布したか確認できない、と。これはウイルス検査の結果ではなく、プログラムの動作に対する判断でもありません。

macOS — Gatekeeper も同じことをします

macOS 版はインストーラではなくフォルダです。展開して中の start.command を開いてください。Python も必要なライブラリもすでにそのフォルダに入っているため、インストール作業はなく、アプリケーションフォルダにも何も追加されません。設定もログもすべてそのフォルダの中だけに書かれ、フォルダをゴミ箱に入れればアンインストールは完了です。

V19.7 の内容

  • 初期設定の安全装置：上場から90日未満の銘柄にはエントリーしない。同じ銘柄・同じ方向で24時間以内に新規エントリーが3回あると、1回目から48時間が経過するまで新規エントリーを停止する。現物の上場廃止も含む上場廃止フィルター。
  • 投資モード（Investment Mode）は常にオンです。標準モードでは、1回のエントリーごとに残高 ÷ 500 を使います。
  • 新規インストール時のレバレッジ初期値は 10x です。既存の設定はそのまま維持されます。
  • 高度なリスク設定と戦略設定はパスワードでロックされています。60% ハードストップのスイッチは引き続き表示されます。
  • 修正：短い（18文字の）Bybit キーで、API キーの手順表示が点滅し続けていた問題。

ダウンロードに関する質問

本当に無料ですか？
はい。サブスクリプションや有料プランはありません。開発者は、取引所のブローカープログラムを通じて、あなたがすでに支払っている取引手数料の一部を受け取ることがあります — 詳しくは「仕組み」のページをご覧ください。
プログラムに出金権限は必要ですか？
いいえ。先物取引の権限だけでキーを作成し、出金は無効のままにしてください。取引所が対応している場合は、キーをご自身のPCの IP アドレスに制限してください。
損失が出ることはありますか？
はい。レバレッジをかけた先物取引では元本をすべて失う可能性があり、初期設定ではストップロスがありません。シャドーモードから始め、失っても問題のない資金だけを使ってください。
取引所のアカウントや API キーなしで試せますか？
シャドーモードは、仮想残高を使って実際の価格で戦略を動かします。実際の注文を出すには、アカウントと API キーが必要です。
どの OS で動きますか？
Windows と macOS です。Android は保留中で、iOS 版はありません。取引中はコンピューターの電源を入れたままにしておく必要があります。
起動すると Windows や macOS が警告を出すのはなぜですか？
このプログラムは個人開発者が作成したもので、有料のコード署名証明書で署名されていないため、OS が発行元を確認できません。ダウンロードページに、開き方とファイルの SHA-256 チェックサムの確認方法を記載しています。
