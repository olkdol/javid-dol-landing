仕組み

JaviD Future Bot は USDⓈ-M 無期限先物向けのデスクトッププログラムです。1人の個人開発者が開発・配布しています。

どこで動くのか

ご自身の Windows または macOS のコンピューターで動きます。取引所で API キーを作成し、プログラムの Settings に入力すると、プログラムがご自身のPCから注文を出します。キーはご自身のコンピューターに保存されます。取引中はPCの電源を入れたままにしておく必要があります。

何を判断するのか

3つのクオンツ戦略が選択された銘柄を監視し、それぞれのルールに従ってポジションを建て、追加します。V19.7 の初期設定の安全装置：上場から90日未満の銘柄には新規エントリーしない。同じ銘柄・同じ方向で24時間以内に新規エントリーが3回あると、1回目から48時間が経過するまで新規エントリーを停止する（保有中のポジションへの追加は数えない）。そして上場廃止フィルター。初期設定ではストップロスはありません。任意で 60% ハードストップをオンにできます。

私の収入の仕組み

プログラムは無料です。サブスクリプションも、ライセンスキーも、有料プランもありません。

取引所がブローカープログラムを運営している場合、あなたがすでに支払っている取引手数料の一部が開発者に分配されます。あなたの手数料はどちらの場合も同じです。

  • Bitget — あなたがすでに支払っている取引手数料の12%。新規アカウント・既存アカウントのどちらも対象です。
  • Binance — 開発者がプログラムに参加した後に開設されたアカウントのみが対象です。すでに Binance アカウントをお持ちの場合、あなたの取引から開発者が得る収入はありません。これを変えるために2つ目の Binance アカウントを開設しないでください。Binance が禁止しています。
  • Bybit と OKX — 利用可能な場合、プログラムには取引所のブローカー識別子またはリファラル識別子が組み込まれています。あなたの手数料は変わりません。
  • コピートレード（Bitget、Bybit） — プロフィールのリーダーとして、開発者は取引所が定めた利益分配をフォロワーの利益から受け取ります。招待リンクには取引所の招待コードが含まれています。

このウェブサイトの登録リンクは取引所の通常の登録ページであり、リファラルリンクではありません。

利益相反について、率直に記載します

取引ごとに収入を得る仕組みは、開発者に取引回数を増やしたい動機を与えます。各ビルドに含まれるエントリールールと初期設定は開発者が決めており、高度な戦略設定はパスワードでロックされています。その初期設定には、取引を減らすルールも含まれています：1銘柄あたり24時間で新規エントリーは最大3回です。あなたの設定はご自身のコンピューター上のファイルに保存され、プログラムの実行中に開発者がそれを見たり変更したりすることはできません。シャドーモードでは、お金をかける前にどのくらいの頻度で取引するかを確認できます。

ご自身で確認できること

  • ダウンロードしたファイルの SHA-256 チェックサムを、ダウンロードページに記載された値と比べてください。
  • 実行中に接続先のホストを一覧表示してください（Windows ではリソースモニター、macOS では lsof -i -P）。
  • 実口座のダッシュボードを見てください — このサイトの1時間ごとのキャプチャと YouTube のライブ配信。
  • 実際の資金を接続する前に、好きなだけシャドーモードで動かしてください。

確認できないこと

ソースコードは公開していません。Windows 版と macOS 版はパッケージ化・難読化されているため、戦略のコードを読むことはできません。使う前にボットのコードをすべて読む必要がある場合は、Freqtrade や Hummingbot などのオープンソースプロジェクトのほうがその目的に適しています。

レバレッジをかけた先物取引では、元本をすべて失う可能性があります。
