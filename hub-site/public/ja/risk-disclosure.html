元本をすべて失う可能性があります

レバレッジをかけた先物取引では、元本をすべて失う可能性があります。ポジションが強制ロスカット（清算）されることがあり、損失がポジションを建てたときの想定を上回ることもあります。

レバレッジと、初期設定でストップロスがないこと

レバレッジが高いほど、強制ロスカット（清算）が近づきます。初期設定ではプログラムにストップロスがないため、ポジションが大きな損失を抱えたまま長期間残ることがあります。任意の 60% ハードストップはこれを制限しますが、その代わりに損失が確定します。

過去の記録

ライブの数値は1つの口座の限られた期間のものです。別の口座、期間、銘柄の組み合わせ、設定では、損失を含めて大きく異なる結果になることがあります。

バックテスト

バックテストは、価格データ、手数料、ファンディング、スリッページ、当時存在した銘柄についての前提を置いて過去を再現したものです。実際の取引で明らかになるような形で誤っていることがあります。このサイトでは、バックテストを実口座の記録と合わせることはありません。

コスト

取引手数料、資金調達率手数料（ファンディング手数料）、スリッページは結果を押し下げます。ポジションを保有している間、ファンディング手数料を支払うことも受け取ることもあります。

コピートレード

フォロワーの結果は、遅延、規模、手数料、利益分配のため、リーダーの結果とは異なります。

API キー

キーの作成、保管、無効化はあなたが行います。出金権限はオフにし、可能であればキーをご自身の IP に制限してください。キーとシークレットを持つ人は誰でも、あなたの口座で取引できます。

ソフトウェアと取引所の障害

プログラム、PC、ネットワーク、取引所が停止したり、予期しない動作をしたりすることがあります。PCの電源を入れたままにし、ポジションは取引所でも直接確認してください。

このサイトの数値の算出方法

実現損益 = プログラムの取引記録にある決済済み取引の損益 + 資金調達率手数料（ファンディング手数料）。保有中のポジションは除外しています。「利益で決済」は損益が 0 を上回る取引を数えます。日付は韓国時間です。1つの口座が標本のすべてです。初期設定ではストップロスがないため、損失中のポジションは決済されるまでこれらの数値に表れません。

利益相反

開発者は、取引所のブローカープログラムを通じて、あなたが支払う取引手数料の一部を受け取ることがあります。「仕組み」のページをご覧ください。

投資助言ではありません

このサイトのいかなる内容も、投資助言や売買の推奨ではありません。判断するのはあなたであり、その結果に責任を負うのもあなたです。
