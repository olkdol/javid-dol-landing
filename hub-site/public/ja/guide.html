使い方

実際のプログラムのスクリーンショットです（Bitget 版、英語 UI、ダミーのキー、何も接続していない状態）。他の取引所のビルドも同じタブとボタンを使います。違いはページ下部にまとめています。

おすすめ：まずシャドーモードで様子を見る

Start Trading を押す前に Operations Console で Shadow Mode をオンにし、数日間動かしてください。実際の注文を出さずに、実際の価格で同じ判断を見ることができます。

1ダウンロード、解凍、起動

お使いの取引所向けのビルドをダウンロードして解凍します。Windows では JaviD_Future_Bot.exe を実行し、macOS では start.command を開きます。プログラムはご自身のPC上のローカルアドレスでブラウザに表示されます。初回起動時のウェルカム画面を閉じるとタブが表示されます。

2Settings — API キーを入力して Save をクリック

Settings タブを開きます。取引所で作成した Access Key と Secret Key を貼り付け（Bitget と OKX では Passphrase も必要です）、Save をクリックします。隣の Test Connection でキーを確認できます。キーの出金は無効のままにしてください。

3Settings — 投資額（Investment Mode）

Investment Mode (Margin Ratio per Entry) で、1回のエントリーに残高のどれだけを使うかを選びます：1エントリーあたりの証拠金 = 残高 ÷ 100、200、300、500、700。初期設定は Normal (÷ 500) で、数字が大きいほど1回のエントリーが小さくなります。モードをクリックするとすぐに適用されます。（Binance 版は Aggressive、Normal、Stable の3つです。）

4Settings — エントリーモード

Entry Mode で、Conservative (single)（最初に条件が合った戦略のみ）か、戦略を順番に使う Multi Mode を選びます。選択はすぐに適用されます。

5Settings — レバレッジ

Leverage で 3x、5x、10x、15x から選びます。新規インストール時は 10x です。設定は次の新規エントリーから適用され、保有中のポジションはそれまでのレバレッジを維持します。レバレッジが高いほど、強制ロスカット（清算）が近づきます。

6Symbol Selection — Select All

Symbol Selection タブを開き、Select All をクリックします（または希望する銘柄だけにチェックを入れます）。

7Symbol Selection — Save Selection

Save Selection をクリックします。その後、プログラムが選択したすべての銘柄のローソク足データを読み込みます。完了するまでお待ちください。

8Start Trading を押す

右上の Start Trading をクリックします。Shadow Mode（右側の Operations Console 内、初期設定はオフ）がオンの場合は、仮想残高で取引します。Shadow Mode がオフの場合は、実際の注文が始まる前に、レバレッジと証拠金の概要を確認する画面が表示されます。

取引所別ビルドの違い

  • Bitget：Access Key、Secret Key、Passphrase。キーには先物の読み取り権限と取引権限が必要です。
  • Binance：Access Key と Secret Key のみ。投資モードは Aggressive、Normal、Stable です。
  • Bybit：API Key と API Secret、パスフレーズなし。アカウントは USDT が入った統合取引アカウント（Unified Trading Account）である必要があり、キーには Contract の注文とポジションに対する Read-Write 権限が必要です。Bybit のキーは18文字です — これは正常です。
  • OKX：API Key、Secret Key、Passphrase。アカウントモードは “Futures mode”（先物モード）で、取引アカウント（Trading account）に USDT が必要です。（ダウンロード準備中）
  • すべてのビルド：キーの IP 制限（IP バインド）を推奨します。また、初回起動時にヘッジ（両建て）モードが自動的にオンになります。

レバレッジをかけた先物取引では、元本をすべて失う可能性があります。 レバレッジが高いほど、強制ロスカット（清算）が近づきます。初期設定ではプログラムにストップロスがないため、ポジションが大きな損失を抱えたまま長期間残ることがあります。任意の 60% ハードストップはこれを制限しますが、その代わりに損失が確定します。
