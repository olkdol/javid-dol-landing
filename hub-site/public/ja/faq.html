よくある質問

本当に無料ですか？
はい。サブスクリプションや有料プランはありません。開発者は、取引所のブローカープログラムを通じて、あなたがすでに支払っている取引手数料の一部を受け取ることがあります — 詳しくは「仕組み」のページをご覧ください。
プログラムに出金権限は必要ですか？
いいえ。先物取引の権限だけでキーを作成し、出金は無効のままにしてください。取引所が対応している場合は、キーをご自身のPCの IP アドレスに制限してください。
損失が出ることはありますか？
はい。レバレッジをかけた先物取引では元本をすべて失う可能性があり、初期設定ではストップロスがありません。シャドーモードから始め、失っても問題のない資金だけを使ってください。
取引所のアカウントや API キーなしで試せますか？
シャドーモードは、仮想残高を使って実際の価格で戦略を動かします。実際の注文を出すには、アカウントと API キーが必要です。
どの OS で動きますか？
Windows と macOS です。Android は保留中で、iOS 版はありません。取引中はコンピューターの電源を入れたままにしておく必要があります。
起動すると Windows や macOS が警告を出すのはなぜですか？
このプログラムは個人開発者が作成したもので、有料のコード署名証明書で署名されていないため、OS が発行元を確認できません。ダウンロードページに、開き方とファイルの SHA-256 チェックサムの確認方法を記載しています。
このサイトのライブの数値は何を意味していますか？
実際の Binance 口座1つのものです：そのダッシュボードの1時間ごとのスクリーンショットと、その口座自身の取引記録から算出した数値です（決済済み取引 + ファンディング手数料。保有中のポジションは除外）。初期設定ではストップロスがないため、損失中のポジションは決済されずに保有されたままとなり、数値ではなく保有ポジションのスクリーンショットに表示されます。1つの口座の限られた期間が標本のすべてです。
バックテストはありますか？
現時点ではありません。以前のバックテストは、集計の誤りが見つかったため取り下げました。新しいバックテストは、検証を経た後にのみ、実口座の記録とは分けて表示します。
コピートレードはプログラムとどう違いますか？
コピートレードは取引所のページで行われ、何もインストールしません。あなたの結果はリーダーの結果とは異なります。Bitget と Bybit のプロフィールはコピートレードのページに掲載しています。Binance と OKX は準備中です。
質問はどこでできますか？
メール（support@javidtrading.com）、Telegram コミュニティ、またはコミュニティ掲示板でお問い合わせください。
