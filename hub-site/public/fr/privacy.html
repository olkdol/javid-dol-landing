Le programme

Le programme s'exécute sur votre ordinateur. Votre clé API et vos paramètres y sont stockés. Le programme n'envoie au développeur ni votre clé, ni votre solde, ni vos trades.

Téléchargements

Lorsque vous téléchargez une version, le serveur de téléchargement du sous-domaine de cette plateforme (bg., bn. ou bb.javidtrading.com) enregistre une ligne : l'heure, la plateforme (Windows ou macOS), le pays indiqué par le réseau, le nom d'hôte du site d'origine, les balises de campagne UTM, la page de ce site d'où vous venez, un type de client approximatif (navigateur, bot, script) et la valeur Sec-Fetch-Site du navigateur. Votre adresse IP et votre user agent complet ne sont pas conservés. Cela sert à compter les téléchargements et à voir quels canaux fonctionnent.

Stockage du navigateur

Ce site conserve votre provenance dans le stockage de session de votre navigateur (effacé à la fermeture de l'onglet), afin qu'un téléchargement puisse être attribué à ce canal.

Forum communautaire

Le nom et le message que vous publiez sont stockés. Pour les messages privés, c'est un hachage salé de votre mot de passe qui est stocké, pas le mot de passe.

E-mail et Telegram

Si vous nous écrivez, nous conservons la conversation pour vous répondre.

Tiers

Le site est servi par Cloudflare. Les polices sont chargées depuis jsDelivr. Les liens vers les plateformes et YouTube vous mènent à ces services, soumis à leurs propres politiques.

Contact

Questions ou demandes de suppression : support@javidtrading.com.
