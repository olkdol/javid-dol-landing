Premier lancement : votre ordinateur va afficher un avertissement

Windows et macOS n'omettent cet avertissement que pour les logiciels signés avec un certificat de signature de code — un produit payant, renouvelé chaque année, délivré à une société enregistrée. Je n'en ai pas acheté. Votre ordinateur dit donc la vérité : il ne peut pas vérifier qui a publié ce fichier. Ce message n'est pas un résultat d'antivirus, ni un jugement sur ce que fait le programme.

macOS — Gatekeeper fait la même chose

Le téléchargement macOS est un dossier, pas un installateur. Décompressez-le et ouvrez start.command à l'intérieur. Python et les bibliothèques nécessaires sont déjà dans ce dossier : il n'y a aucune étape d'installation et rien n'est ajouté à votre dossier Applications. Tout ce qu'il écrit — vos réglages, vos journaux — reste dans ce dossier, et le glisser à la Corbeille constitue la désinstallation complète.

Questions sur le téléchargement

Est-ce vraiment gratuit ?
Oui. Il n'y a ni abonnement ni offre payante. Le développeur peut recevoir une partie des frais de trading que vous payez déjà, via les programmes de courtier (broker) des plateformes — détails dans Fonctionnement.
Le programme a-t-il besoin de la permission de retrait ?
Non. Créez la clé avec uniquement le trading de contrats à terme et laissez les retraits désactivés. Si la plateforme le permet, limitez la clé à l'adresse IP de votre PC.
Puis-je perdre de l'argent ?
Oui. Les contrats à terme avec effet de levier peuvent vous faire perdre la totalité de votre capital, et il n'y a pas de stop-loss par défaut. Commencez en Shadow Mode et n'utilisez que de l'argent que vous pouvez vous permettre de perdre.
Puis-je l'essayer sans compte sur une plateforme ni clé API ?
Le Shadow Mode exécute les stratégies sur les prix en direct avec un solde virtuel. Pour passer des ordres réels, il vous faut un compte et une clé API.
Sur quels systèmes fonctionne-t-il ?
Windows et macOS. Android est en attente et il n'existe pas de version iOS. Votre ordinateur doit rester allumé pendant qu'il trade.
Pourquoi Windows ou macOS m'avertit-il quand je l'ouvre ?
Le programme est conçu par un développeur individuel et n'est pas signé avec un certificat de signature de code payant, donc le système d'exploitation ne peut pas vérifier l'éditeur. La page de téléchargement montre comment l'ouvrir et comment vérifier la somme de contrôle SHA-256 du fichier.
