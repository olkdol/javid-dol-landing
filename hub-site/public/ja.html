1時間ごとに更新

いま稼働している実口座1つについて、プログラム自身のダッシュボードを1時間ごとにキャプチャした画面です。YouTube でライブ配信している画面と同じものです。この1口座が標本のすべてです。

同じダッシュボードを YouTube でライブ配信しています

ダッシュボードの見出しには “V18.4” と表示されますが、プログラム自体が報告するバージョンは 19.7 です（/health エンドポイントで確認）。

稼働中の実口座1つの取引記録から算出

決済済み取引と資金調達率手数料（ファンディング手数料）のみを集計しています。このプログラムは初期設定ではストップロス（損切り）がないため、上場廃止に伴う決済や強制ロスカット（清算）を除き、損失中のポジションを自ら決済しません。損失がこれらの数値に現れるのは、ポジションが損失で決済されたときだけで、それまでは保有中のポジションに残ります。保有中のポジションはこれらの数値に含まれません — ダッシュボードの表示そのままに「保有中のポジション」のスクリーンショットで確認できます。

ダッシュボードの “Total N Trades” と Win Rate には、ファンディング手数料の記録も含まれています。ここではファンディング手数料を別に数えているため、2つの数値は異なります。 損益がちょうど 0 で決済された取引は、利益にも損失にも数えません。

日別の累積実現損益（USDT）

決済済み取引の損益とファンディング手数料を日ごとに合計し、累積したものです。口座残高の推移ではなく、保有中ポジションの含み損はここに表示されません。

プログラムの機能

ご自身のPCで動作 利用可能

注文はご自身のコンピューターから、ご自身の API キーで取引所へ直接送られます。間に当方のサーバーはありません。

シャドーモード 利用可能

仮想残高を使って実際の価格で戦略を動かすため、実際の注文を出す前に動作を見ることができます。

3つの戦略、500以上の銘柄 利用可能

どの USDⓈ-M 先物銘柄を監視するかはご自身で選びます。戦略はボラティリティの高いアルトコイン向けに調整されています。

初期設定のエントリー制限 利用可能

上場から90日未満の銘柄は対象外です。同じ銘柄・同じ方向で24時間以内に新規エントリーが3回あると、1回目から48時間が経過するまで新規エントリーを停止します。保有中のポジションへの追加はこの回数に含まれません。

上場廃止フィルター 利用可能

取引所の公開アナウンスに基づき、上場廃止が告知された銘柄を避けます。

初期設定ではストップロスなし 利用可能

ポジションが大きな損失を抱えたまま長期間残ることがあります。Settings で任意の 60% ハードストップを使えます。

大型銘柄（BTC/ETH）プリセット 開発中

大型銘柄向けに調整したプリセットを開発中です。現在のビルドには含まれていません。

Android 保留中

安定して動作するまで Android 版は保留しています。現時点では Windows と macOS のみです。
