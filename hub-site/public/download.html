First run: your computer will warn you

Windows and macOS skip this warning only for software signed with a code-signing certificate — a paid item, renewed yearly, issued to a registered company. I have not bought one. So your computer is telling you the truth: it cannot verify who published this file. That message is not a virus scan result, and it is not a judgement about what the program does.

Windows — the Run button is hidden until you click More info

1. What you see first

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognised app from starting. Running this app might put your PC at risk.
More infoDon't run

There is only a “Don't run” button at this point. The Run option does not exist yet — this is where most people give up.

2. After clicking More info

Windows protected your PC
App: JaviD_Future_Bot.exe Publisher: Unknown publisher
Run anywayDon't run

Clicking “More info” reveals “Run anyway”. Click it and the app starts normally. Wording varies between Windows versions.

macOS — Gatekeeper does the same thing

The macOS download is a folder, not an installer. Unzip it and open start.command inside. Python and the libraries it needs are already in that folder, so there is no install step and nothing is added to your Applications folder. Everything it writes — your settings, your logs — stays inside that folder, and dragging the folder to the Trash is the whole uninstall.

macOS 15+

“start.command” Not Opened
Apple could not verify “start.command” is free of malware that may harm your Mac or compromise your privacy.
Move to TrashDone

Open it once and let it fail. Then go to System Settings → Privacy & Security, scroll down, and click “Open Anyway”. I list this route first because it does not depend on which version of macOS you are on.

because it is from an unidentified developer.

Control-click start.command, choose Open, then Open again in the dialog. If Open is not in that menu, use the Settings route above.

The exact wording differs between macOS versions. If your screen says something close to this but not identical, you are in the right place.

What's in V19.7

  • Default safeguards: no entries on symbols listed less than 90 days ago; after 3 new entries on the same symbol and side within 24 hours, new entries are blocked until 48 hours after the first; delisting filter including spot delistings.
  • Investment mode is always on; the standard mode sizes each entry at balance ÷ 500.
  • Default leverage 10x for new installs. An existing setting is kept.
  • Advanced risk and strategy settings are behind a password lock; the 60% hard-stop switch stays visible.

Download questions

Is it really free?
Yes. There is no subscription or paid tier. The developer can receive part of the trading fee you already pay through exchange broker programs — details on How it works.
Does the program need withdrawal permission?
No. Create the key with futures trading only and keep withdrawals disabled. If the exchange allows it, restrict the key to your PC's IP address.
Can I lose money?
Yes. Leveraged futures can lose your entire capital, and there is no stop-loss by default. Start in Shadow Mode and only use money you can afford to lose.
Can I try it without an exchange account or API key?
Shadow Mode runs the strategies on live prices with a virtual balance. To place real orders you need an account and an API key.
Which systems does it run on?
Windows and macOS. Android is on hold and there is no iOS version. Your computer has to stay on while it trades.
Why does Windows or macOS warn me when I open it?
The program is made by an individual developer and is not signed with a paid code-signing certificate, so the operating system cannot verify the publisher. The download page shows how to open it and how to check the file's SHA-256 checksum.
