## 무엇을 했나

### ① `install-help.html` — 6개 사이트에 배치
자체 완결형 1파일이고 **8개 언어(en/ko/ja/es/fr/vi/tr/pt)를 내장**했습니다.
`?lang=ko` 로 열리고, 없으면 브라우저 언어로 자동 선택, 상단 버튼으로 전환됩니다.
→ 언어별로 파일을 8개 만들 필요가 없습니다. 번역 누락 검사도 통과했습니다(35키 × 8언어 = 전부 정의됨).

내용 구성:
- **누가 만들었나** — *"회사가 아니라 개인 개발자 한 사람이 만들고 배포한다"* 를 명시(요구사항 3)
- **왜 경고가 뜨나** — 유료 코드서명 인증서 미보유. **바이러스 검사 결과가 아님**을 분명히 함
- **윈도우 절차** — 🔑 **핵심**: 첫 화면에는 "실행 안 함" 버튼밖에 없고,
  **"추가 정보"를 눌러야 "실행"이 나타난다.** 대부분이 여기서 포기한다.
  → 클릭 전/후 다이얼로그를 **CSS 로 재현해 나란히** 보여줍니다(스크린샷 미사용 — 버전·언어마다
    화면이 달라 정지 이미지 하나는 오히려 혼란을 주고, 순서를 보여줄 수 없기 때문)
- **macOS 절차** — ⚠️ **Sequoia(15.0+)부터 Control-클릭 우회가 제거됨.**
  현재는 *한 번 실행해 실패 → 시스템 설정 → 개인정보 보호 및 보안 → "무시하고 열기"*.
  macOS 14 이하는 우클릭 → 열기. **둘 다 안내합니다.**
- **직접 확인하는 법** — VirusTotal(실행 전) · 리소스 모니터/`lsof -i -P`(실행 후, 호스트 2곳)
  → "그냥 눌러 넘기세요"로 쓰지 않았습니다. 그건 나쁜 습관을 가르치는 것이고 우리 전제와 어긋납니다.

## 검토·보완 부탁드릴 것

1. **`bybit-site` / `okx-site` 는 링크를 못 넣었습니다.** 다운로드 버튼이 `href="#download"` 앵커
   방식이라 마크업이 다릅니다. `install-help.html` 파일은 이미 배치돼 있으니 링크만 걸어주시면 됩니다.
   (다만 두 거래소는 **아직 브로커 승인 전**이라 우선순위는 낮다고 봅니다.
    참고로 `okx.javidtrading.com` 은 현재 **배포되어 200 응답**합니다.)
2. **`hub-site` 는 자체 다운로드 버튼이 없어** 넣지 않았습니다. 허브는 bg/bn 으로 보내므로
   목적지에서 안내를 만납니다. 의도한 동작입니다.
3. 문구·디자인이 각 사이트 톤과 맞는지 봐주세요. 스타일은 전부 인라인이라 기존 CSS 와 충돌하지 않습니다.

## 배포

**추가 작업 없이 `push.bat` 을 누르면 반영됩니다.** Cloudflare Pages 가 자동 재배포합니다.

⚠️ `push.bat` 은 `git add .` 라 **저장소의 모든 미커밋 변경을 함께 커밋**합니다.
작업 중인 파일이 있으시면 push 전에 `git status` 로 확인해 주세요.
현재 스테이징 대기: 수정 16개 + 신규 6개(`install-help.html`) + 이 요청 문서들.
